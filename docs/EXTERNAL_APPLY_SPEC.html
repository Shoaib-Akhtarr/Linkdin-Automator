Apply pipeline: fixed flow

Four diagrams, linked by blue hand-off nodes. Red nodes are exits, each with a status code from the table at the bottom.

1. Entry and routing

Pre-flight uses status classes. A form that is already open (Greenhouse, Lever, Ashby) now skips the guest and auth checks.

2. Auth and 2FA

2FA is checked before the landing check. Registration saves a pending vault entry before it clicks Register. Push and link timeouts exit as a timeout instead of asking for a code.

3. Upload and wizard

The step counter is set once and never reset by a loop. The heal counter resets only after a clean step. Certifications are ticked only if the profile has an opt-in flag.

flowchart TD
I([from 1 or 2: Form ready]):::go --> UP[Upload tailored resume]
UP --> PS{Spinner gone and inputs settled, 15s?}
PS -->|Stalled| X1([FAIL: RESUME_UPLOAD]):::ex
PS -->|Yes| IN[Init wizard ONCE: stepCounter=0, healAttempts=0]
IN --> SL{Session still valid?}
SL -->|Expired| X2([FAIL: SESSION_EXPIRED]):::ex
SL -->|Yes| CAP{stepCounter below 12?}
CAP -->|No| X3([FAIL: WIZARD_LOOP]):::ex
CAP -->|Yes| EX[Scan visible fields]
EX --> TR[Split into Tier 1 deterministic and Tier 2 generative]
TR --> T1[Tier 1 from profile.json: sanitize phone and date, work auth, salary, years of exp, EEO, certifications with opt-in flag]
T1 --> TC{Mandatory Tier 1 field missing?}
TC -->|Yes| X4([HOLD: MISSING_LEGAL_CONFIG]):::ex
TC -->|No| T2[Tier 2 LLM: essays, motivation, cover letter, grounded in CV facts]
T2 --> BT{Primary button?}
BT -->|None or unknown| X5([FAIL: NO_ACTION_BUTTON]):::ex
BT -->|Submit or Complete| SUB([to 4: Submit and Verify]):::go
BT -->|Next or Continue| NX[Click Next]
NX --> CP{CAPTCHA on transition?}
CP -->|Yes| XC([BLOCK: CAPTCHA, stage=step]):::ex
CP -->|No| VE{Validation errors?}
VE -->|None| AD[stepCounter++, healAttempts=0]
AD --> SL
VE -->|Errors| HC{healAttempts below 1?}
HC -->|No| X6([FAIL: STEP_VALIDATION]):::ex
HC -->|Yes| LT{Failed field is Tier 1?}
LT -->|Yes| X7([HOLD: LEGAL_FIELD_REJECTED]):::ex
LT -->|No| HR[healAttempts++, re-select or re-format]
HR --> T2

4. Submit and verify

Every unconfirmed outcome is recorded as HOLD, so the pre-flight check never retries it automatically.

flowchart TD
I([from 3: Submit page]):::go --> MG{Execution mode?}
MG -->|Autonomous| CP
MG -->|Review or Hybrid| PR[Chime and alert: ready for review, 300s]
PR --> HD{Decision?}
HD -->|Approve| CP
HD -->|Reject| X1([HOLD: CANCELLED_BY_USER]):::ex
HD -->|Edit or takeover| X2([HOLD: HANDED_OFF_TO_USER]):::ex
HD -->|Timeout 300s| X3([FAIL: TIMEOUT_USER_REVIEW]):::ex
CP{CAPTCHA before submit?}
CP -->|Yes| X4([BLOCK: CAPTCHA, stage=submit]):::ex
CP -->|No| SB[Click Submit once]
SB --> ER{Inline validation errors?}
ER -->|Yes| X5([FAIL: STEP_VALIDATION]):::ex
ER -->|No| OB[Wait for network idle 15s, watch DOM]
OB --> RC{Proof: URL pattern, submitted header, reference ID?}
RC -->|Confirmed| OKR[Record APPLIED_CONFIRMED with attempts, time, CV path]
OKR --> DN([DONE: APPLIED]):::ok
RC -->|Unconfirmed or network drop| SE{Portal or email API confirms?}
SE -->|Yes| OKR
SE -->|No| UV[Record UNVERIFIED_MANUAL_CHECK]
UV --> X6([HOLD: SUBMISSION_UNVERIFIED]):::ex

Status classes

Pre-flight reads the class of the last record in applications.json. Every failure increments attemptsCount.

ClassPre-flight ruleStatuses
DONESkip for 90 daysAPPLIED_CONFIRMED
HOLDNever retry automatically; the user clears itUNVERIFIED_MANUAL_CHECK, CANCELLED_BY_USER, HANDED_OFF_TO_USER, BLOCKED_SSO_ONLY, BLOCKED_UNSUPPORTED_AUTH, FAILED_MISSING_LEGAL_CONFIG, FAILED_LEGAL_FIELD_REJECTED
COOLDOWNSkip for 7 days; at attemptsCount 3 it becomes HOLDBLOCKED_CAPTCHA (with stage), BLOCKED_ACTIVATION_PENDING, TIMEOUT_2FA, TIMEOUT_USER_REVIEW, FAILED_PORTAL_UNREACHABLE, FAILED_GUEST_APPLY_LOAD, FAILED_OAUTH_NO_FALLBACK, FAILED_CREDENTIALS_REJECTED, FAILED_AUTH_CYCLE, FAILED_REG_POLICY, FAILED_MASTER_PASSWORD_REJECTED, FAILED_2FA_EXHAUSTED, FAILED_POST_AUTH_FORM_LOST, FAILED_RESUME_UPLOAD, FAILED_SESSION_EXPIRED, FAILED_WIZARD_CYCLIC_LOOP, FAILED_WIZARD_NO_BUTTON, FAILED_STEP_VALIDATION
